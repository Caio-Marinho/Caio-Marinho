Gosto de pegar um problema real e transformar em algo que funcione, seja uma API, uma automação ou uma ferramenta para facilitar o dia a dia. No código, costumo me preocupar com o caminho completo: validar os dados, tratar erros, deixar os logs úteis e documentar o que a próxima pessoa (ou eu daqui a alguns meses) vai precisar entender.

Tenho trabalhado bastante com **Python**, APIs e integrações, mas também gosto de explorar o front-end e aprender como as peças se conectam. Fora das aplicações, mantenho scripts para deixar meu ambiente Linux/WSL do meu jeito. ☕

## 🚀 Coisas que venho construindo

- [**Gerenciador de Chamados**](https://github.com/Caio-Marinho/gerenciador-chamados) — um projeto full stack para abrir, distribuir e acompanhar chamados, com FastAPI, SQLAlchemy, MySQL e interface web.
- [**my-linux-setup**](https://github.com/Caio-Marinho/my-linux-setup) — scripts Bash para instalar e atualizar ferramentas e preparar meu ambiente de desenvolvimento no Linux/WSL.
- **APIs e integrações** — no trabalho em equipe, tenho atuado em serviços web com validação de dados, documentação OpenAPI, cache, middlewares e logs para facilitar a operação e o diagnóstico.
